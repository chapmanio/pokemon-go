# Project guidance

Use `CONTEXT.md` for domain terminology and `docs/product.md` and `docs/features.md` as the product source of truth.

Read `docs/data-sources.md` and `docs/reliability.md` before changing external data integrations, caching, or estimates. Read `docs/roadmap.md` before starting new feature work.

Keep the app a generic Pokémon GO companion. Update the relevant document when a product decision changes; avoid duplicating decisions across documents.
