# Discovery fixtures

These are small, hand-trimmed samples of live provider payloads captured on
2026-10-27. They preserve the source shapes needed for adapter and validation
tests; they are not current-roster data for the app.

- `raid/pogoapi.json` — reference raid boss fields.
- `raid/leekduck.json` — roster fields and Shadow identity.
- `raid/pokemon-go-api.json` — form-aware roster and precomputed estimate fields.
- `raid/pokebattler-counter.json` — nested counter and simulation result fields.

Refresh the samples when an adapter contract changes, and keep the capture date
in the test metadata rather than treating fixture contents as live truth.
